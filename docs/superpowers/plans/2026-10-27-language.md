# FolderSize Language Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Tiếng Việt / English đổi ngay, lưu lựa chọn và phát hành 1.2.0 sạch.

**Architecture:** App.Localization.LanguageService cung cấp indexer, Culture và event; catalog JSON nhúng và binding markup extension. Preferences đọc/ghi atomically một mã ngôn ngữ. VM nhận service, refresh thuộc tính chứ không rebuild cây.

**Tech Stack:** C# .NET10/WPF, System.Text.Json, xUnit, UI smoke có sẵn.

**Spec:** docs/superpowers/specs/2026-10-27-language-design.md

## Global Constraints
- Tiếng Việt mặc định; English en-US. Giữ nguyên path/tên file và dữ liệu quét.
- Lưu settings trong LocalApplicationData, không sửa cấu hình người dùng trong test.
- Không đăng ký event cho từng node; không phá ảo hóa/recycle-only.
- Release một EXE + LICENSE, không PDB.

## Review Focus
1. File settings thiếu/hỏng/không ghi được: app vẫn chạy, lựa chọn hiện tại vẫn đổi và có thông báo khi lưu thất bại.
2. Đổi ngôn ngữ khi đang quét/đã hoàn tất: không đổi state/selection/expanded paths hoặc nhận status cũ bằng ngôn ngữ sai.
3. Nhãn/cột/tooltip trong các template WPF phải đổi cùng nhau, kể cả các dòng tái sử dụng.
4. Chuỗi xác nhận và lý do chặn recycle giữ đầy đủ ý nghĩa bảo vệ dữ liệu bằng hai ngôn ngữ.
5. Single-file phải nhúng catalog; gói chỉ có exe/LICENSE và vẫn mở được.
